# Clasificación de fallas en maquinaria rotativa

Proyecto del curso Despliegue de Soluciones Analíticas (MIAD - Uniandes).

## Estructura
- `src/`: scripts reutilizables (extracción de características, modelo, API)
- `notebooks/`: exploración de datos
- `reports/`: figuras, mockup y documentos del reporte
- `data/`: datos versionados con DVC (`raw/` señales originales, `features/` tabla de características). No se suben a GitHub.

## Datos
Machinery Fault Database (MaFaulDa), SMT/UFRJ.
